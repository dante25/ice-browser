# Ice core build

Custom ungoogled-chromium 156.0.8078.79-1 build with Ice's built-in features as
**component extensions** (decision: approach A, see docs/CORE-BUILD-REPORT.md).

## Contract (shared by all parts)

- Base: Chromium tag `156.0.8078.79` + ungoogled-chromium `156.0.8078.79-1` patches
  (+ ungoogled-chromium-portablelinux `156.0.8078.79-1` patches).
- Our patches: `core-build/patches/ice-NN-<name>.patch`, unified diff, `a/` `b/` prefixes,
  paths relative to the Chromium `src/` root, applied with `patch -p1` (in NN order)
  AFTER all ungoogled patches. Each patch must apply cleanly on top of the
  ungoogled-patched tree (check ungoogled `patches/series` for files we touch).
- Extension files are NOT patched. They are copied byte-for-byte at packaging time to
  `<install dir>/resources/ice-builtins/<dir>/` (= `chrome::DIR_RESOURCES`/ice-builtins,
  DIR_RESOURCES = DIR_ASSETS/resources = directory of the `chrome` binary + `/resources`).
  Mapping (dir name -> repo source):
  - adblock-for-youtube, bookmarks-clean-up, chrome-tab-counter,
    default-quality-adjuster-for-youtube, enable-right-click-for-google-chrome,
    go-back-with-backspace, hide-anything-element-hider-for-chrome,
    hide-labels-and-end-cards-on-youtube, multiselect-for-youtube,
    permanent-progress-bar-for-youtube, screenshot-youtube, search-by-image,
    tab-session-manager, webmail-ad-blocker, youtube-nonstop  -> chrome-extensions/<dir>
  - ice-shield, google-images-viewer, ice-newtab -> ice-features/<dir>
- NOT built in (stay separate, normal extensions): Ultimate SN Downloader, Video Sniffer.
- Pref with on/off switch (only one): `ice.builtins.multiselect_youtube_enabled`
  (bool, profile pref, default true, applied after restart).
- Common C++ helper (patch ice-01): `chrome/browser/extensions/ice_builtins.h/.cc`,
  namespace `ice`, with
  `bool IsIceBuiltinExtension(const extensions::ExtensionId& id);`
  (true for the IDs below) and `inline constexpr char kMultiselectEnabledPref[] =
  "ice.builtins.multiselect_youtube_enabled";`.

## Patches (core-build/patches/, applied in order after ungoogled patches)

- ice-01-component-loader: `ice_builtins.h/.cc` + ComponentLoader loads the built-ins from `<resources>/ice-builtins/` (file thread, localized manifest). Before loading, every file is checked against SHA-256 hashes compiled into the browser (`ice_builtins_files.inc`, generated by `core-build/gen-ice-builtins-files.py` right after patching); extra, missing or modified files -> built-in is not loaded. ID must match the compiled-in ID. Multiselect is skipped when its pref is off.
- ice-02-dnr-component-static-rulesets: static DNR rulesets of component extensions are indexed on first load into `<user data>/Ice Component Rulesets/<id>/<version>/` (Ice Shield GPC/HTTPS rules).
- ice-04-settings-pref: registers `ice.builtins.multiselect_youtube_enabled` (no UI yet; GUI phase).
- ice-05-builtins-normal-privileges: built-ins keep normal Web Store privileges: no scripting on chrome:// / Web Store / other extensions, no file:// unless allowed, incognito off by default.

GUI patches (toolbar/puzzle menu, settings toggle) are deferred to the GUI phase (`core-build/patches-gui/`, see docs/GUI-PLAN.md).
